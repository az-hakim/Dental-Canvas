# Dental Canvas v1.4.29

Released 2026-11-05.

## A settings page that fits the job

Settings had grown to sixteen tabs laid out shoulder to shoulder — a clinic
changing its working hours had to read past Rx templates, storage, backups and
a Resend API key to find them. The page now opens in **Basic**, showing only the
five things a practice configures day to day:

**Profile · Appearance · Hours · Notifications · Billing**

A **Basic / Advanced** switch sits above the tabs. Advanced reveals the whole
set in the same bar, with the technical and one-off screens separated from the
basics: Account, Operatories, Practitioners, Treatment types, Consent forms,
Online booking, Email, Rx templates, Storage, Backup and About.

- **Nothing moved or was removed.** Every tab is exactly where it was in
  Advanced mode, and the page still opens on the tab you were last using.
- **The switch is remembered** on this device, so a front-desk machine can stay
  on Basic while the doctor's machine stays on Advanced.
- **No dead ends.** Returning to Basic while an advanced tab is open lands on
  Profile rather than leaving a hidden tab selected.

Everything else — the local database, sync, printing and the offline app — is
unchanged.
